# Add listings

To add a listing, sign in to the admin dashboard and press the “New listing” button on the Listings page.

For each listing, you will need the following information:

* **Title** — the name of the group or organisation (required)
* **Category** — one of your web's categories (required)
* **Description** — a short description of what the group does (required). You can format the text, and even add images or embed videos.
* **Image** — a photo or logo that represents the group
* **Contact email for organisation** — if your web has a contact email set in Web Settings, we will send a courtesy email to this address letting the group know their listing was created
* **Website** and **social media links** — Facebook, Instagram, X/Twitter and more
* **Location** — where the group is based, so it can appear on the map. Some groups don't have a fixed address, in which case you can tick “No physical location”.

There are also a few optional extras:

* **Tags** — cross-category labels that visitors can filter by. You can create new tags directly from the listing form.
* **Related listings** — link the listing to other groups it is connected to; these are shown on the listing page and visualised on the web.
* **Currently seeking volunteers** — displays a badge on the listing, and visitors can filter the web to show only groups looking for volunteers.
* **Mark as inactive** — hides the listing from the public web without deleting it, useful for groups that have paused their activities.

Once you have added a listing, there might be a slight delay before it appears on the web.
