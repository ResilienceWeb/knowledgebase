# Create and edit categories

Every listing on your web belongs to a category, and the category determines the colour of the listing on the web. New webs come with a set of default categories (Community, Education, Environment, Food, Health, Human rights, Social justice) which you are free to rename, delete and add to however you want.

To manage categories, sign in to the admin dashboard and go to the **Categories** page. From there you can:

* **Add** a new category
* **Edit** an existing category, where you can change its name, colour and icon
* **Delete** a category you no longer need

If you set a custom icon for a category, it will also be used for the markers in the Map view (for webs that have the map enabled).
