# Add and update neighbouring webs

If there are other webs that are close geographically or related to yours in some way, you can link to them so that visitors can discover them from your web.

1. Sign in to the admin dashboard and go to **Web Settings** (only web owners can access this page).
2. Scroll down to the **Related/neighbouring webs** section and select the webs you want to link to.

<figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

3. Press **Update** to save your changes.
